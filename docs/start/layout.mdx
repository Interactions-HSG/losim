## Your project

```
proto/                   your schema
src/                     your Java
gen/                     generated from the schema. Gitignored and never edited.
simulations/*.yaml       simulation files

build.gradle.kts         dissaly, protoc, and the toolchain task
dissaly                    the launcher: `./dissaly simulate`, `./dissaly serve`
AGENTS.md                what `dissaly adopt` left for you, if it left anything
build/results/           your traces, and a bill beside each
```

<Note>
**The project needs no `lib/`, `docs/`, or `viewer/` directory.** dissaly supplies the
manual and console inside its jar. `./dissaly serve` and `./dissaly serve docs` use those
bundled resources, while project copies take precedence when present.
</Note>

<Note>
The project has no separate manifest. It compiles its `.java` and `.proto` files
together, and a simulation selects a class by path:
`runs: { Thumbnailer: src/lab/Shrinker.java }`.

**One code folder, many simulations.** Keep code in `src/` and vary system topology,
network conditions, and failures in separate simulation files. The console's
**Simulations** page writes them to `simulations/`.

**Your Java names dissaly in one place.** The entry class implements `dissaly.Job`, a
service defined in dissaly's schema. Other code under `src/` can compile without the
simulator. Call costs, node types, and failures belong in the simulation.
[How a project gets this shape ->](/start/adopt)

`build/` and `gen/` are gitignored. Traces are generated artifacts; the evaluator
reruns the code rather than relying on an exported picture.
</Note>

This section applies when working on dissaly itself. These paths are outside an
assignment:

```

bin/dissaly                the CLI: build, then run it. Every command here is one of its verbs
dissaly/test/              dissaly's own acceptance criteria     (`dissaly dev test`)
tests/                   the reference suite, run end to end (`dissaly dev suite`)

prices/                  course data: what egress costs, what being late costs
vendor/                  grpc 1.83.1, protobuf 4.36.0, protoc for two platforms
build/                   generated, all of it. The viewer's committed export is viewer/out.


dissaly/src/dissaly/api/     what a handler may say to dissaly and all it can reach
dissaly/src/dissaly/runtime/ the system, the nodes, the two interceptors
dissaly/src/dissaly/trace/   the three-channel recorder and the trace it writes
```

## Source dependency rule

<Warning>
**Your code compiles against `build/dissaly.jar` and the vendored jars. It does not
compile against `dissaly/src`.**

The jar exposes `dissaly.api`, which has no dependency on runtime types. Handlers can
therefore compile and unit-test without a running simulator. Code that imports
`dissaly.runtime` would be coupled to the simulator.
</Warning>

This is the command used to compile a project; you do not type it directly:

```bash
javac --release 21 -cp "$(cat build/dissaly/classpath)" -d build/dissaly/classes \
      $(find gen src -name '*.java')
```


## `build/`, after a run

| | |
|---|---|
| `build/dissaly.jar` | the simulator |
| `build/dissaly/classes/` | your compiled system — this is what `--cp` points at |
| `build/<simulation>.json` | the trace, unless `--out` said otherwise |
| `build/results/` | **where to point `--out`** — the viewer picks up whatever is here |
| `build/.dissaly-plans/` | cached scale plans, keyed on the simulation, the code and the telemetry level |

Fitting a scale plan runs a grid of about thirty small runs and the result is cached.
Delete `build/.dissaly-plans` to force a refit. [More on that ->](/engine/probe-grid)

## Seeing a run

The lab server lists traces under `build/results`, and `show()` in
`RunExperiments.java` opens the viewer on its runs. [The viewer ->](/viewer/index)


## The manual's own check

```bash
bin/dissaly dev docs check
```

The manual is checked against the coursework rules in `docs-check/`. The check also
tests itself with known-bad and known-good samples before scanning the pages, and CI
runs it on every push.
