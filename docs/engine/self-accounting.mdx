## Measurement contamination

dissaly runs on the node's own threads. Each span operation allocates memory and
consumes wall-clock time **on the threads whose allocation and duration are being
measured**.

The counters see both allocations. dissaly measures its own contribution and removes
it from the node totals.

<Warning>
The overhead is roughly constant **per call** and is independent of the data size.
In `demand = c + a·n^b`, it therefore lands in `c`. The probe grid runs at small
`n`, where a fixed term is proportionally largest.

Without subtraction, the overhead inflates `c`, changes the fitted exponent, and
gets extrapolated to full scale.
</Warning>

## Accounting mechanism

Every region of dissaly's own work is bracketed:

```java
long a0 = Meter.allocNow(), t0 = System.nanoTime();
// dissaly's work
node.charge(Meter.allocNow() - a0, System.nanoTime() - t0);
```

The charge goes into the node ledger and enclosing span. Reported allocation and
handler duration then exclude dissaly's work.

```java
public long allocatedBytes() {
    return Math.max(0, rawAllocatedBytes() - dissalyBytes.get());
}
```

## Implementation details

<AccordionGroup>
  <Accordion title="The bracket uses explicit counter reads" icon="code" defaultOpen>
    Constructing a lambda would allocate against the node **before the first mark
    is read**. The two `Meter.allocNow()` calls are therefore written out at each
    bracket.
  </Accordion>

  <Accordion title="Outside the bracket: calibrated and charged back" icon="magnifying-glass">
    A bracket reads the clock and allocation counter twice. The **first read of each
    pair occurs before there is anything to charge it to.**

    It is measured once per JVM, around **70 ns** on a reference laptop, and charged
    back per metered stop. This prevents instrumentation from increasing the billed
    node work.
  </Accordion>

  <Accordion title="Primitive `reveal` overloads avoid call-site boxing" icon="box">
    `reveal(String, Object)` boxes an `int` at the **call site**, before the bracket
    opens. The box is charged to your program even though it exists only because the
    parameter is an `Object`.

    Passing the primitive keeps the boxing inside the bracket.

    At one call per handler this is small. At a thousand it bends the fitted memory
    exponent by **0.04**.
  </Accordion>
</AccordionGroup>

## Measurement boundary

In `reveal("keys", map.size())`, the `size()` is **your** work and is charged to your
program. Everything after the argument has been evaluated is dissaly's.

Similarly, `Dissaly.current().sleep(refMs)` charges the bookkeeping while leaving
**the wait itself outside the bracket**. The wait is the program's declared
duration. Charging it to dissaly would remove the work the span is intended to
measure.

## Node-local subtraction

<Note>
Only what landed on **this node's own threads** can be taken back off it.

An async response is delivered on the channel's executor, which is not a node.
Its bytes were never counted against a node, so subtracting them would credit the
node for work it did not perform. The wall-clock charge still applies to the span,
but the allocation charge does not.
</Note>

## Sampler thread

The sampler runs on `dissaly-sampler`, outside every node pool, so its work does not
enter the counters it reads.

## Published in the trace

```json
{ "name": "w0", "allocMb": 388.4, "dissalyMb": 0.44, "dissalyStops": 1284 }
```

<Note>
*"`allocMb` is the program's own"* is a **claim**. The trace includes both the bytes
removed and the number of metered stops so the claim can be checked.
</Note>

## Verification

Measured at the extreme, a thousand `reveal` calls per handler make dissaly charge
itself **54 MB** and meter **162,000 regions**:

| | moves by |
|---|---|
| the **unsubtracted** memory exponent | 0.026 — well outside its own noise |
| the **reported** exponent | 0.0004 — inside it |

Across four levels of instrumentation (telemetry off, no payloads, everything
rendered, and a thousand reveals per handler), the fitted allocation exponent moves by
0.0001 while dissaly's own charge goes from 0.31 MB to 54.19 MB.

<Warning>
**The extreme case is mandatory.** At one `reveal` per handler, a leak that halved an
exponent could remain undetected. The projected law must be independent of the
amount of instrumentation.
</Warning>
