Build a small thumbnail system. A master reads an album, sends splits of
frames to nodes that serve the thumbnail service, and collects the results. The
later steps add failures so we can inspect the system's response.

The tutorial focuses on the system *shape*: how services are arranged so losim
can measure them. The thumbnail algorithm stays simple.

## System shape

```
  master (m5.large, eu-central-1a)   runs losim.Job
      │
      ├── w0  c5.large  eu-central-1a  ┐
      ├── w1  c5.large  eu-central-1b  │  all four serve Thumbnailer
      ├── w2  c5.large  eu-central-1a  │  so the Job finds them by that,
      └── w3  a1.medium eu-central-1b  ┘  found by service
```

`w3` has **one core while the other workers have two**. It does less work in the
same interval and costs less, which makes the effect of placement visible.

## Result

The run produces a trace with events, node activity, and a four-bucket bill. A
later step kills a node and shows the master detecting the failure through
the call deadline.
