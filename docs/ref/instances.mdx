## The families

<Columns cols={2}>
  <Card title="a1 — narrow" icon="compress">
    The **straggler generator**, and the only nodes here with **one** core. Every
    other type has at least two, so these are the only way to say *half the node
    the others are*: one call at a time, and declared work takes twice as long. Put
    an `a1.medium` in a pool of `c5.large`s — a quarter of the price and half the
    node — and find out whether your placement notices.
  </Card>
  <Card title="m5 — balanced" icon="scale-balanced">
    The default. Use it when the point of the simulation is not the nodes.
  </Card>
  <Card title="c5 — compute" icon="gauge-high">
    More cores per franc, less memory. `c5.4xlarge` is the one to reach for when you
    want real contention inside one node — sixteen threads on one pool.
  </Card>
  <Card title="r5 — memory" icon="memory">
    Twice the memory of an `m5` at the same core count. The shape for a design that
    holds things.
  </Card>
</Columns>

`i3.large` is the storage-shaped one — 475 GB against everyone else's 8 to 32.

## Derived from the row

<ParamField path="vCPU" type="int">
  The size of the node's **thread pool**, and its speed relative to the reference
  node: `machineFactor = 2 ÷ vcpu`. A `c5.4xlarge` runs an 8 refMs
  handler in 1 refMs; an `m5.large` takes the full 8, and an `a1.nano` takes 16.
</ParamField>

<ParamField path="memory" type="MB">
  The default memory cap, enforced against the retained-heap walk. Overridable per
  node with `memoryMb:` in a scale of 1; **solved by the engine** above `scale: 1`.
</ParamField>

<ParamField path="storage" type="GB">
  The default disk cap. `wroteDisk` throws past it.
</ParamField>

<ParamField path="$/hour" type="double">
  The on-demand rate, used by the bill's **capacity** bucket. A node that received
  a `spot_notice` is billed at the spot rate — 70% off by default.
</ParamField>

<Note>
**What a node costs to rent lives here, not in the price list.** It is a property
of the node, beside its vCPUs and its memory, rather than a choice the course
makes. Two places declaring what an `r5.large` costs would be two places to drift
apart, and the drift would be silent.
</Note>

## Choosing them

<Tip>
The most instructive system is not a uniform one:

```yaml
workers:
  count: 4
  prefix: w
  instance: c5.large
  runs: { Thumbnailer: src/lab/Shrinker.java }
  overrides:
    w3: { instance: a1.medium }
```

Three compute nodes and one that will fall behind. Whether your coordinator
notices — and what it does about it — is the whole exercise, and a system of four
identical nodes cannot ask the question.
</Tip>
