```java
dissaly.api.Spec spec = Dissaly.current().here();
```

```java
public record Spec(String node, String instance, String zone, int vcpu,
                   double memoryCapMb, double diskCapMb) {
    public double cores();      // vcpu / 2.0
}
```

<ResponseField name="node()" type="String">The node's name, e.g. `"w3"`.</ResponseField>
<ResponseField name="instance()" type="String">Its instance type, e.g. `"a1.medium"`.</ResponseField>
<ResponseField name="zone()" type="String">Its availability zone.</ResponseField>
<ResponseField name="vcpu()" type="int">How many threads its pool has.</ResponseField>
<ResponseField name="memoryCapMb()" type="double">
  The memory cap it is under **on this run**.
</ResponseField>
<ResponseField name="diskCapMb()" type="double">
  The disk cap it is under on this run.
</ResponseField>
<ResponseField name="cores()" type="double">
  `vcpu / 2.0` is the node's capacity relative to a two-core node.

  This is a capacity ratio, not a placement score. The simulation still decides
  where to place work.
</ResponseField>

## Local knowledge

<Warning>
There is no way to read a **peer's** `Spec`.

An orchestrator can read its own limits and instance metadata without a network. It
must ask other nodes for theirs, for example through a gRPC registration call.

The master must account for the fact that reported capacity can become stale.
</Warning>

A service can report its own capacity through an RPC:

```java
@Override protected Health capacity(Empty request) {
    var spec = Dissaly.current().here();
    return Health.newBuilder()
            .setMachine(spec.node())
            .setInstance(spec.instance())
            .setZone(spec.zone())
            .setVcpu(spec.vcpu())
            .setMemoryCapMb(spec.memoryCapMb())
            .build();
}
```

## Scaled caps

`memoryCapMb()` and `diskCapMb()` are the limits for this node **on this run**, not
the instance type's full-scale values. Above `scale: 1`, the engine solves for them.

This lets a job that compares caps place work the **same way at either scale**.

## Cost of access

The node builds the record once, before it boots. Reading its fields is not measured
or charged.

## Outside a run

Throws, like every other state call:

```java
assertThrows(IllegalStateException.class, () -> Dissaly.current().here());
```
