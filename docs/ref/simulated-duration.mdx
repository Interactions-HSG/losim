```yaml
simulatedDuration:
  src/Shrinker.java:
    Thumbnail: { fixed: 3 refMs, perUnit: 240000 refNs }
    Capacity:  { fixed: 1 refMs }
```

Each top-level key is a path named by `runs:`. Under that path, list an RPC served
by the file's class. Both values default to `0`; an RPC with no entry takes **no
time**.

<ParamField path="fixed" type="duration" default="0">
  What one call takes **regardless of its contents**. dissaly applies it before the
  handler runs.
</ParamField>

<ParamField path="perUnit" type="duration" default="0">
  What each processed unit adds. The handler declares the count with
  `Dissaly.current().units(n)`. dissaly sleeps this part **after the body returns** and
  before the response leaves, when the handler has reported the processed amount.

  Use `refNs` for small per-unit costs; milliseconds per unit can be too large.
</ParamField>

Both carry their unit in the value, the way [every other duration](/ref/durations)
in the file does.

## Declaration location

`retries:` names a method, such as `Thumbnailer.Thumbnail`, because retrying is a
decision about a *call*. A duration is a property of the *code*, so two
implementations of one RPC can have different entries.

The key is the same path used by `runs:`. Moving the file requires updating both
entries.

## Keep declarations in the simulation

The duration is declared in the simulation rather than in the handler. Handlers
remain plain gRPC classes that compile and unit-test without dissaly on the classpath.

The table can drift from the implementation, so dissaly checks it against the services
the nodes actually serve before a run:

```
thumbs.yaml:31: simulatedDuration names 'src/Shrinker.java Thumbnial', and
src/Shrinker.java serves no rpc of that name. It serves Capacity, Thumbnail. A cost
that belongs to nothing is a method that quietly takes no time, so it is a refusal
rather than a warning.
```

A system that prices **nothing** is valid. The trace reports it because zero-cost
calls produce no queueing, contention, or critical-path time.

## Sleep formula

```
fixed x (2 / vcpu) x degradeFactor x slowFactor / k_time
```

Reference time is two vCPUs running alone. A 4-vCPU node takes half as long, a node
under `degrade: 4` takes four times as long, an RPC under
[`slow: 6`](/ref/failures) takes six times as long **on that node only**, and the
whole run is compressed by `k_time`.

## Purpose of duration declarations

dissaly shrinks the workload **and** the nodes by the same factor, so memory and bytes
remain comparable. Host CPU time does not scale with the modeled workload, so
handlers can appear instant without declared durations. Without a duration there is
no queueing, contention, deadline pressure, or critical path.

Measuring durations at probe size is unreliable because host jitter can dominate the
handler time.

## Work and waiting

| | `simulatedDuration:` | `Dissaly.current().sleep(refMs)` |
|---|---|---|
| meaning | declared **work** | a declared **wait** |
| fixed per rpc? | yes, it is a table | no, the program decides |
| stretches on a slow node? | **yes** | no |
| occupies a vCPU? | **yes** | no |

At 40x on a node at half speed, a declared 500 takes 1019 refMs and
`sleep(500)` takes 596. A backoff that grows with the attempt must be computed by
the program, so the table and `sleep` cover different cases.

## Timer floor

The clock cannot express a duration finer than about **0.05 ms** of real time. Below
that, the ledger records the cost as owed and settles it later. The engine refuses to
project a cost that remains below the floor at its selected compression:

```
this run is clocked at 40x real time, and src/Shrinker.java Capacity costs 0.0004
refMs — 6x below what the sleep debt can still settle at that compression, so its
timings would drift rather than be owed. Give that cost site more to do, or lower
the scale: at scale 1 the clock runs at 20x.
```
