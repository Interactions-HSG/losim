A cluster, its weather and its bad afternoon — as data. Nothing here is authored
that the run could find out for itself; anything that needs code points at a class
by name, so the file stays diffable,
sweepable and readable by someone who did not write it.

## Every top-level key

```yaml
seed: 7                       # long,     default 1
job: lab.ThumbnailJob         # class,    required
scale: 5000                   # number,   default 1, at least 1
tightMargin: false            # bool,     default false
mode: direct                  # direct | scaled, default direct

machines: { … }               # required, at least one
network:  { … }
faults:   [ … ]
chaos:    [ … ]
retries:  [ … ]
```

Any other key at this level is refused with the line it was written on.

<ParamField path="seed" type="long" default="1">
  Everything random draws from it: chaos placement, network jitter, packet loss,
  and your own workload through `cluster.seed()`. `--seed` overrides it.
</ParamField>

<ParamField path="job" type="class name" required>
  Fully qualified. Must implement `losim.api.Job` and have a no-argument
  constructor. Runs on the **first machine in the file**.
</ParamField>

<ParamField path="scale" type="number" default="1">
  How many times bigger the design is than the run measuring it. At 1 there is no
  model: the input is exactly what `input:` says and every number is what happened. See
  [scale](/ref/scale).
</ParamField>

<ParamField path="mode" type="direct | scaled" default="direct">
  There are exactly two, and no third. Scaled mode always uses the engine: a
  hand-declared shrink factor would be a third mode whose numbers nobody could
  account for.
</ParamField>

<ParamField path="tightMargin" type="boolean" default="false">
  Recorded in the trace's `meta` as a marker for exercises where the margin between
  a design working and not working is deliberately thin.
</ParamField>

## The rule that governs the whole file

<Warning>
**Everything that can be wrong is refused at load, with the line it was written
on** — an unknown key, an unknown instance type, a duration that forgot its unit, a
fault aimed at a machine that is not in the cluster, a retry policy the schema does
not support, two machines with the same name.

Nothing runs, and the exit code is 2. None of these should be discovered halfway
through a run as a puzzling number.
</Warning>

## A complete example

```yaml
seed: 7
job: lab.ThumbnailJob
scale: 500
mode: scaled

machines:
  coordinator:
    instance: m5.large
    zone: eu-central-1a

  workers:
    count: 4
    prefix: w
    instance: c5.large
    zone: [eu-central-1a, eu-central-1b]
    runs: [lab.Shrinker]
    overrides:
      w3: { instance: a1.medium, memoryMb: 512 }

network:
  sameZone:  0.4 refMs
  crossZone: 3 refMs
  jitter:    0.5 refMs
  loss:      0.01

faults:
  - { at: 900 refMs,  kill: w1, restart_after: 400 refMs }
  - { at: 1200 refMs, degrade: w2, factor: 4 }
  - { at: 1600 refMs, partition: [coordinator, w0] }
  - { at: 2400 refMs, heal:      [coordinator, w0] }

chaos:
  - freeze: { every: 900 refMs, among: workers, for: 120 refMs }

retries:
  - { method: Thumbnail, attempts: 3, backoff: 50 refMs, multiplier: 2 }
```
