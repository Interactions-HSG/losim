```json
"nodes": [
  { "name": "w0", "instance": "c5.large", "zone": "eu-central-1a", "vcpu": 2,
    "serves": ["render.Thumbnailer"],
    "memoryMb": 41.2, "allocMb": 388.4, "diskMb": 0.0,
    "wireMb": 6.31, "inMb": 24.9, "crossZoneMb": 3.4,
    "egressMb": { "eu-central-1": 1.1, "ap-northeast-1": 2.3 },
    "calls": 41,
    "losimMb": 0.44, "losimStops": 1284,
    "memCapMb": 4096.0, "alive": true }
]
```

## Closing measurements

<Note>
These are **closing measurements**, not samples. Billing, comparisons, and the
viewer use them directly instead of reconstructing peaks from sampled data.

losim performs a final heap walk after `Job.Run` returns, so the result includes
a node that filled up during the last tick.
</Note>

## Identity

| field | |
|---|---|
| `name` | |
| `instance` | its instance type |
| `zone` | |
| `vcpu` | |
| `serves` | the **service** names it offered, as `runs:` keyed them |
| `memCapMb` | the cap it was under on this run |
| `alive` | whether it survived to the end |

## Activity

| field | |
|---|---|
| `memoryMb` | **peak retained heap**, the largest retained value measured |
| `allocMb` | everything it allocated, losim's own subtracted |
| `diskMb` | bytes declared through `wroteDisk` |
| `wireMb` | bytes out |
| `inMb` | bytes in |
| `crossZoneMb` | bytes this node's calls sent across a zone boundary **in both directions**, including the request and response |
| `egressMb` | the same bytes again, split by the **region** they went to. Absent when nothing left the zone |
| `calls` | handlers it completed |

<Warning>
`memoryMb` and `allocMb` measure different things. Streaming and accumulating can
produce similar allocation totals, but only retained memory counts toward an
out-of-memory failure.
</Warning>

## losim overhead

| field | |
|---|---|
| `losimMb` | bytes losim itself allocated on this node's threads, and took back off `allocMb` |
| `losimStops` | how many times it stopped to meter |

These values show how much losim removed from `allocMb`.
[Self-accounting](/engine/self-accounting)

## Units

Values use megabytes to six decimal places. The scale engine uses the same unit
for observed and projected laws, preserving small measurements.

## Read the data

```python
import json
t = json.load(open("build/thumbs.json"))
print(f'{"node":<12} {"calls":>6} {"held MB":>9} {"cap MB":>9} {"out MB":>9}  alive')
for m in sorted(t["nodes"], key=lambda m: -m["memoryMb"]):
    print(f'{m["name"]:<12} {m["calls"]:>6} {m["memoryMb"]:>9.2f} '
          f'{m["memCapMb"]:>9.0f} {m["wireMb"]:>9.2f}  {m["alive"]}')
```
