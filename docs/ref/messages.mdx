## The two shapes losim will not price

<Warning>
Both are **refused**, not flagged, and that is the opposite of what the trust
verifier does. Every rule the verifier catches yields a wrong number *beside a
marker saying it is wrong*. These two yield a wrong number that **looks right**,
and a law fitted to either comes out smooth, confident and false.
</Warning>

<ParamField path="a streaming rpc" type="refused">
  The cost model is one request and one response. `refNsPerUnit` is slept inside
  `sendMessage`, so on a stream it is paid once per **message** rather than once per
  call; and `refMs` is paid at half-close, which for a client-streaming or
  bidirectional handler is *after* the work it stands for.

  The remedy is a unary rpc. There is no flag that makes a stream priceable.
</ParamField>

<ParamField path="a marshaller that is not protobuf" type="refused">
  Every byte losim counts is the serialized size of a protobuf message. A JSON or
  byte-array marshaller ;  grpc-java's `advanced` and `preserialized` examples both
  use one ;  has no such size, so the call would weigh nothing on the wire and cost
  nothing in the bill.

  Checked on the **marshaller**, not on the schema descriptor: losim builds one
  method descriptor by hand for its own warm-up, and it carries no schema while
  being perfectly ordinary protobuf.
</ParamField>

## Wiring up

| message | fix |
|---|---|
| `no class called 'lab.Shrinkr' is on the classpath` | check `--cp` and the spelling. `runs:` names a **class**, fully qualified |
| `'lab.Shrinker' is not a gRPC service` | it must extend the `ImplBase` protoc generated |
| `'lab.Shrinker' needs a no-argument constructor` | losim builds a fresh one when a machine restarts |
| `'lab.MyJob' is named as the job, so it has to implement losim.api.Job` | |
| `no class called 'lab.MyJb' is on the classpath to run as the job` | |
| `could not start machine w0: ...` | usually a name still held by a previous run's server |
| `there is already a machine called 'w1'` | |

## During a run

| message | meaning |
|---|---|
| `w3 has no disk left: 33.4 MB written against a 32.0 MB volume` | working as intended ;  `wroteDisk` throws past the cap |
| `w2 ran out of memory: 11.83 MB against a 4.0 MB cap` | the retained-heap walk found it over. The machine is killed. |
| `this thread has no machine: work started on a thread the machine did not create ...` | [concurrency](/write/concurrency) |
| `no simulation is running, so Losim.current().peers() has no answer here` | a state call in a unit test |
| `there is no machine called 'w9'; this cluster has ...` | `channelTo` with a name that is not in the cluster |
| `DEADLINE_EXCEEDED: w1 did not answer (unreachable)` | dead, partitioned or lost ;  `why` says which |
| `DEADLINE_EXCEEDED: the network outlasted the deadline` | the callee answered, but the round trip took too long |
| `the job was still running after 120 seconds of real time` | a backstop, not a deadline ;  the line between slow and stuck |

## At the end

| message | meaning |
|---|---|
| `trust: 4 machines report figures that do not mean what they say` | [trust rules](/ref/trust-rules). Nothing was stopped. |
| `none of the classes this scenario names are on the classpath it was given ...` | point `--cp` at a **directory**; a jar is not walked |
| `ABANDONED ;  the run ended while this was in flight` | a span that was still open when the run ended. Normal. |
| `losim: w0 did not release its name in time` | shutting the machine down took longer than two seconds. Harmless for the trace, which is already written ;  but if you run several clusters in one JVM, the next one may fail to bind that name. |


## From the scale engine

| message | what to change |
|---|---|
| `the ladder bends: over the lower half it grows as units^0.59 ...` | move the probe ladder to one side of the threshold |
| `its exponent moves by 0.66 between independent seed sets ...` | normal for the timeline; give handlers more to do, or accept it |
| `it was never measured above zero, so there is nothing to fit` | your system never used that resource |
| `nothing measured varied with it, so it has no law here` | the job probably ignores the `Input` it was handed |
| `memoryMb at 8000 units is only 2.4x its own fixed overhead ...` | bigger rungs on the ladder |
| `at 8000 units the cluster would hold 4200 MB, and this host offers 1843 MB ...` | more heap, or a smaller rung |
| `this run is clocked at 40x real time, and ... costs ... refMs` | a cost site too fine for the clock; there is no compression to turn down |
| `no size on the ladder satisfies every resource at once` | |

## Exit codes

| | |
|---|---|
| `0` | the job completed |
| `1` | the job did not complete, or scaled mode found no feasible size |
| `2` | the scenario is wrong. Nothing ran. |
| `3` | something inside losim. `LOSIM_DEBUG=1` prints the stack. |
